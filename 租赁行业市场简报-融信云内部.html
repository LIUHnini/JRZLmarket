金租整体情况、分布与分层

资产规模

2025 年末行业总资产约 5.23 万亿元，同比约 +7.9%（银行业协会《中国金融租赁行业发展报告（2026）》）。

现

现状：三轨并行

  • 1机构管理：以 2024 年《金融租赁公司管理办法》夯实资本与股东责任
  • 2业务边界：金规〔2023〕8 号 + 鼓励 / 负面 / 正面清单明确「有所为、有所不为」
  • 3操作规范：金规〔2025〕25 号细化尽调—审批—合同—租后，突出以租赁物为核心
  • 4科技与治理同步加严：评级含信息科技（约 10%）；合规、董监高、数据安全制度并行
趋

趋势：三条主线

  • 1回归「融资 + 融物」本源：压缩通道与不当结构，提升直租、经营性与真租赁物管理
  • 2产业引导：设备更新、绿色低碳、算力与集成电路等高端制造 / 新质生产力
  • 3数据与系统留痕：EAST / 报表、租赁物数据、数据安全与信息科技能力影响评级与检查
  • 4结论：合规与科技正从「配套支持」变为展业与持续经营能力的组成部分
  • 5行业观察：短期合规成本上升；长期质量提升、头部集中，中小更多深耕农机、专精特新等细分
  • 25 号：适格尽调、独立评估、禁低值高买；租后定位 / 监控与价值覆盖；评处分离；经营性租赁原则上至少每年重估；员工行为管理；核心风控不得外包；自动化审批须模型治理；第 57 条全流程信息科技系统。
  • 监管数据体系：1104、EAST、人行大集中 / 金数、利率报备、征信、反洗钱，以及区域特色与总行报表；银行「一表通」全面推广对共享型金租有传导影响。

25号：https://www.gov.cn/gongbao/2026/issue_12606/202603/content_7061750.html

未来趋势 · 五篇大文章

业务方向 A：五篇大文章

合并为总板块观察；下表按五条线展开。各线展业仍须服从上一页「回归租赁本源」总要求。

科技金融

半导体设备、工业母机、AI 算力 / GPU 集群、检验检测仪器等。协会公开口径：算力租赁余额约 973 亿、同比约 +110%，为近年增速最快的设备类赛道之一；正面清单亦增补算力中心设备、集成电路相关标的。

代表性落点

  • 兴业等布局 IDC / 半导体设备租赁
  • 招银等公开涉及卫星等航天相关租赁探索
  • 高值、技术迭代快的设备直租与厂商协同

数字化含义

高值物独立评估与估值模型；技术迭代下的残值与再投放；租后状态 / 利用率监测；与算力机房、厂商台账的数据衔接。

绿色金融

光伏、风电、储能、新能源车船及配套充换电等。协会口径新型储能余额约 567 亿、同比约 +155%；华夏 / 招银等绿色余额与投放占比已成公开对标样本，户用与分布式光伏呈现批量资产特征。

代表性落点

  • 华夏绿色租赁余额、户用光伏规模（公开评级 / 官网口径）
  • 招银绿色投放占比；浦银等光伏专项
  • 新能源车队、绿航与储能项目租赁

数字化含义

绿色认定与披露口径；批量电站 / 车队资产台账与监控；发电量、运营数据与风险预警联动；补贴与电费回款类场景的对账能力。

普惠金融

农机、工程机械、商用车、中小设备及厂商租赁渠道。强调下沉获客与批量进件，同时须守住租赁物真实性与合作机构管理边界。

代表性落点

  • 江苏金租：农机厂商租赁、乐租系列数字化
  • 工程机械与商用车厂商 / 经销商合作
  • 中小设备零售与区域渠道下沉

数字化含义

渠道门户与批量进件；合作机构与回购管理；评分模型与自动化审批治理；物联网定位与租后巡检；反欺诈与用途监测。

养老金融

康复护理、医院及康养机构设备等。公开可核的专项标杆相对少于科技、绿色、普惠三类，实务上多并入医疗设备或大健康板块观察，表述宜审慎。

代表性落点

  • 医院影像、检验、康复护理设备直租 / 回租
  • 康养机构设施与专用设备（个案为主）
  • 与医疗设备租赁能力复用较多

数字化含义

准入尽调偏医疗设备特征；资质与许可核验；租后巡检与维保记录；残值与二手医疗设备处置合规要求更高。

数字金融

双向含义：一是对客数字化设备与场景（数字化办公、智能终端等可租赁标的）；二是机构对内的数据平台、监管报送与智能能力建设——后者往往是金租差异化与评级相关的主战场。

代表性落点

  • 对客：数字化、智能化设备直租场景
  • 对内：交银机船数字化监控；浦银「租赁大脑」类能力；江苏数据平台
  • 报送、指标与智能体建设并行

数字化含义

数据中台 / 指标与驾驶舱；监管报送与一表通传导；AI 智能体与模型治理；数据安全与信息科技管理（评级权重相关）。

点睛：五篇大文章是「往哪投」；回归本源是「怎么投得合规、管得住物」。科技线的算力与绿色线的储能，已有协会增速数据可引用；养老线公开样本少，汇报中宜单独注明。

国产大飞机 / 船舶与航运装备

国产民机机队扩张与航运装备更新，是机船基本盘上的结构性增量。农银等公开披露国产飞机机队与客户数量靠前；工银、交银等在航空 / 海事板块持续加码。数字化侧重机队船队台账、适航 / 船级信息、残值与退租转租。

造

工业机器人与产线设备更新

制造业设备更新与智能化改造带动产线、工业机器人、检测与工控设备直租需求。鼓励清单与「新质生产力」表述下，直租交付、安装验收与物全生命周期管理能力要求上升。

工

大型工程机械

新机投放、厂商合作与经营性 / 融资性并存。与普惠线下的工程机械渠道有交叉，但高端与大型设备更强调估值、利用率与再投放；IoT 与租后状态是系统常见增强点。

新

中银等公开提及低空经济加速布局；招银等有卫星租赁相关公开信息。整体仍处探索与个案验证阶段，书面宜表述为「观察中 / 探索中」，避免写成已形成规模赛道。

AI 算力租赁

数据中心与基础设施

数据中心与基础设施情况

跟发起行 / 金融云

金租主流模式。信创、等保、数据出域与安全基线多跟行；集团金科常参与建设与运维。采购易受短名单约束。

独立机房 / 专有云

部分大型或产业系金租。自主权较高，改造与运维成本自担；仍需满足金融业安全与监管要求。

公有云 / SaaS

中小融租更为常见。关注数据驻留、托管资质与等保；金租侧相对谨慎，多用于非核心或创新试点。

  • 分层差异：第一梯队多具备较完整的双活 / 灾备与金融云能力；第二梯队受预算与集团统筹影响大；腰部机构基础设施投入更克制。
  • 对厂商含义：部署与集成方案需提前确认「是否必须进金融云 / 是否过金科安全评审」。

数字化建设痛点（对应可立项机会）

  • 口径
    业务 / 财务 / 监管三套口径不一致机会：数据标准、指标口径统一、报送质量治理
  • 监管赶工
    EAST / 报表升版频繁，临时脚本难沉淀机会：统一报送平台、校验规则库、变更响应运维

    租赁物台账—监测—估值—处置链路不贯通，与 25 号差距大机会：全生命周期物管、与 EAST 租赁物主题贯通
  • 核心难换
    核心系统替换成本高，只能旁路增强机会：旁路模块（物管 / 治理 / AI / 报送）与核心厂商联合
  • 编制依赖
    科技编制有限，知识沉淀在驻场厂商 / 金科机会：可移交的产品化能力、知识库与运维包
  • AI 基础弱

  • 江苏：乐租渠道采集 → 湖仓与标准质量 → 物估价 / 反欺诈 → 数字营销与运营分析。
  • 浦银 / 民生 / 招商租赁：租赁大脑；物联网物管 + OCR/RPA；船舶物联网与数据治理综合平台。

金租预算与采购决策的常见模式

模式决策特征外部厂商注意点
金租内部自主采购科技、业务、风险合规、财务会签；相对独立 IT可直销；需对齐多角色关注点
总行 / 发起行把控短名单、架构与安全基线、数据出域审核先确认是否在短名单 / 能否借道银行生态
集团金科统筹或联合金科集成与运维，外部提供专项产品宜联合金科，避免单打独斗拼总包
集团内部集采 / 框架续维、通用软件、云资源等走集采关注框架协议与入围节奏
  • 混合情形常见：业务系统相对独立，监管数据 / 云 / 安全跟行——约访需问清「哪一块必须过总行或金科」。
  • 关键角色：科技（架构信创）· 业务条线（投放与管物）· 风险合规（报送口径）· 财务（预算）· 发起行科技 / 金科（短名单）。

招投标与预算

常见采购方式与预算收紧下的取向

采购方式

多见：邀请招标、竞争性磋商、竞争性谈判。
相对较少：公开招标（金额大或制度强制时）。
亦见：单一来源 / 续建（监管紧急升版、原厂维保延续等）。

预算与评标

近几年 IT 预算普遍承压。价格权重上升，最低价得满分情形多见。大而全总包更难；可验收的小切口、联合存量厂商 / 金科更现实。

分层年 IT 预算量级（示意）举例印象
头部约 3500 万–8000 万级国银、交银、浙银、浦银、民生、外贸等
二梯队约 1200 万–2500 万级农银、华夏、北银、哈银、华融等
小型约 200 万–400 万级中煤科工、稠州、广融达等

数据相关规划约占 IT 预算约 10%，新签落地约 5%——存在共创立项空间。人月示意约 2.5–4.5 万（以公司商务政策为准）；融租 SaaS 多为年费 + 实施费。

预算为内部调研脱敏口径，勿对外报价引用。

监管报送与一表通

监管报送与一表通

  • 监管报送范围：金监 1104 非现场监管报表；EAST（监管数据标准化，含租赁物等主题域）；人民银行金融统计大集中、金融基础数据库（金数）、利率报备；征信报送与查询；反洗钱；以及区域特色报表、总行并表报表等。
  • 建设要点：多源采集、制度变更快速响应、校验规则与质量闭环、与核心 / 数仓接口稳定；从「能报」升级到「报得准、改得快、留得住痕」。
  • 一表通：银行机构监管报表「一表通」已进入全面推广（金发〔2025〕20 号等）；目标是明细级标准化、提升时效、减轻多头报送。金租非银行主体，但深度共享型金租常被发起行数据体系带着走，外部机会多在转换、一致性校验、主题补齐与联合金科实施。
  • 媒体披露：部分监管局辖内达标银行须于 2026 年 6 月底前实现报送，另有批次于 2026 年底、2027 年底；双轨并行期内原有系统仍可能继续报送。
  • 痛点：制度多、口径不一、临时脚本多；租赁物与业务数据质量直接关系 EAST 合规与检查问责。

信创国产化

信创国产化：分层与常见产品

金租多跟发起行 / 集团信创规划与集采目录推进；既有「平台 + 应用」打包，也有应用层单独适配，需评估与金科、存量核心兼容。

层级常见国产化方向（不完全列举）

租赁物管理

租赁物管理系统：三类建设形态

监管驱动：2024 年管理办法 + 金规〔2025〕25 号对管物提出更高要求，并要求全流程信息系统支撑。

1

全生命周期类

侧重台账、权证、价值、保险、运营状态、盘点、维保等通用管理能力；与核心合同 / 放款及 EAST 租赁物数据贯通。适用面广，是多数金租的「管物底座」。

2

租赁物运营管理类

侧重设备日常运营与监控，专业性强、物类差异大。例如：车辆运营管理、充电桩运营管理、光伏运维管理等。一般由合作方或金租建设专门运营系统，再回传关键状态 / 风险数据至核心或物管平台。

3

机船资产管理系统

单体金额大、项目数量相对少。机船规模达到一定体量后，公司常成立子公司承建，或建设独立业务管理系统，覆盖授信审批、合同放款、资产管理等一系列功能（如机船监控、残值与退租处置等）。

数据治理 · AI · 数据安全

数据治理 · AI · 数据安全

DATA GOVERNANCE

数据治理类

把「能报」做成「报得准、用得上」

  • 数据标准与指标口径统一
  • 数据质量检核与问题闭环
  • 元数据、血缘与影响分析
  • 客户 / 合同 / 租赁物主数据
  • 可与报送、一表通、AI 前置绑定立项
痛点对应：口径不一致、监管赶工脚本化
AI APPLICATION

AI 类

底座 + Agent + 智问，小切口可验收

  • AI 底座：模型网关、知识库、权限审计
  • Agent：报送校验、租后解释、尽调辅助
  • 智问：制度与知识问答
  • 影像 / OCR：合同与物证辅助识别
  • 约束：脱敏、审计、责任部门；不替代核心风控
痛点对应：AI 基础弱、演示多立项少
DATA SECURITY

数据安全类

金规〔2024〕24 号等专项能力提升

  • 组织责任与数据安全责任制
  • 分类分级与重要数据识别
  • 脱敏、访问控制、加密与审计
  • 安全运营与专项评估
  • 金租侧常经集团安全基线传导
与信创、云上线、检查驱动常同批推进
内部能力契合讨论：租赁物全生命周期与 25 号同向；监管数据 + AI 助手对准刚需；姿态宜「可被金科 / 核心集成的专项能力」。产品名待校准。
